🎬 Movie Rating Prediction Using Machine Learning

📌 Project Overview

The Movie Rating Prediction project uses Machine Learning to predict movie ratings based on available movie-related information.

The system analyzes features such as movie genres, popularity, and other available details to estimate a movie's rating.

The main objective is to understand how Machine Learning can be applied to movie rating prediction and recommendation-related applications.

🎯 Project Objectives

- Analyze movie datasets.
- Clean and preprocess movie information.
- Identify important movie features.
- Build Machine Learning prediction models.
- Predict movie ratings.
- Compare two Machine Learning algorithms.
- Evaluate prediction performance.
- Visualize model results.

🧠 Algorithms Used

1. Linear Regression – Main Algorithm

Linear Regression is a supervised Machine Learning algorithm used to predict continuous numerical values.

In this project, it is used to estimate movie ratings based on available input features.

Why Linear Regression?

- Suitable for numerical prediction.
- Simple and easy to understand.
- Identifies relationships between features and ratings.
- Provides a useful prediction baseline.

2. Random Forest Regressor – Comparison Algorithm

Random Forest Regressor is an ensemble Machine Learning algorithm that combines multiple Decision Trees to predict continuous values.

Why Random Forest Regressor?

- Captures complex relationships.
- Handles different input features.
- Combines predictions from multiple trees.
- Helps compare prediction performance.

📈 Model Evaluation

The models are evaluated using:

- MAE: Mean Absolute Error.
- MSE: Mean Squared Error.
- RMSE: Root Mean Squared Error.
- R² Score: Measures how well the model explains rating variation.

Lower MAE, MSE and RMSE indicate smaller prediction errors. A higher R² generally indicates better explanatory performance.
